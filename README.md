# بوت Telegram احترافي لفك الأرشيفات وإدارة الملفات

بوت عربي Modular يستقبل الأرشيفات مباشرة داخل Telegram، يفكها داخل مساحة خاصة بالمستخدم، ويتيح التصفح والبحث وإرسال ملف محدد فقط. يحتوي على SQLite ولوحة إدارة وقنوات اشتراك إجباري وتحويل فيديو/استخراج صوت عبر FFmpeg.

## الحالة الحالية

- قوائم Inline حقيقية: الرئيسية، إدارة الملفات، ملفاتي، الشرح، التنظيف، الفيديو والصوت.
- ZIP وRAR و7Z وTAR/TAR.GZ/TGZ/TAR.BZ2/TAR.XZ.
- متصفح مجلدات، بحث، إرسال ملف واحد، حذف ملف، استخراج الكل، حذف الأرشيف.
- SQLite للمستخدمين والأرشيفات والملفات والتنزيلات والقنوات.
- لوحة Admin عبر `ADMIN_IDS`، إحصائيات، مستخدمون، حظر/إلغاء حظر، Broadcast، قنوات، تنظيف، إعدادات.
- اشتراك إجباري مركزي مع استثناء المديرين.
- حماية من Path Traversal وZip Slip والروابط الرمزية وحجم/عدد ملفات الأرشيف.
- تحويل الفيديو واستخراج الصوت من خلال FFmpeg إذا أرسل المستخدم فيديو واختار الوظيفة.
- تنظيف تلقائي للملفات المنتهية يدويًا من لوحة الإدارة، وحذف مجلد المهمة عند الفشل.

## المتطلبات

- Python 3.11 أو أحدث.
- Telegram Bot Token من [@BotFather](https://t.me/BotFather).
- 7-Zip وunrar-free لـ RAR/7Z.
- FFmpeg للتحويلات.
- أو Docker، وهو يثبت الأدوات السابقة داخل الصورة.

## إعداد البيئة

```bash
cp .env.example .env
nano .env
```

ضع القيم:

```env
BOT_TOKEN=توكن_البوت
ADMIN_IDS=123456789,987654321
DATA_DIR=data
MAX_FILE_SIZE=20971520
MAX_EXTRACTED_SIZE=209715200
MAX_FILES=100
MAX_CONCURRENT_JOBS=2
MAX_SINGLE_OUTPUT=51380224
RETENTION_HOURS=24
```

لا تضع `.env` في Git، ولا تخزن التوكن في SQLite.

## التشغيل المباشر على Ubuntu

```bash
sudo apt-get update
sudo apt-get install -y python3-venv ffmpeg p7zip-full unrar-free tar
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## التشغيل عبر Docker

```bash
docker compose up -d --build
docker compose logs -f
```

## الإعداد الأول للقنوات

1. أضف البوت إلى القناة، ويفضل أن يكون **مسؤولًا** حتى يستطيع Telegram API التحقق من الأعضاء.
2. ادخل لوحة الإدارة من `/start` ثم `⚙️ لوحة الإدارة` ثم `📢 القنوات المطلوبة` ثم `➕ إضافة قناة`.
3. أرسل `@channel_username` أو `-1001234567890`. للقناة الخاصة أرسل Channel ID مع رابط الدعوة مثل `https://t.me/+xxxxx`.
4. يستطيع المدير تفعيل/تعطيل وحذف القنوات من داخل البوت دون تعديل Python.
5. إذا لم يكن البوت مسؤولًا، سيظهر تنبيه واضح وقد يعتبر التحقق غير متاح، لذلك يجب إعطاؤه الصلاحية المناسبة.

## استخدام المستخدم

- `/start`: التحقق من الاشتراك وعرض القائمة.
- أرسل Archive كـ **Document**، لا كصورة.
- بعد الفك تظهر بيانات الأرشيف وأزرار التصفح والبحث وإرسال ملف محدد.
- يمكن اختيار `🎬 تحويل الفيديو` أو `🎵 استخراج الصوت` ثم إرسال الفيديو.
- زر تنظيف الملفات يعرض المساحة؛ حذف الأرشيف يتم من صفحة الأرشيف، والتنظيف العام من الإدارة.

## الاختبارات

اختبارات محلية حقيقية:

```bash
pytest -q
```

تغطي ZIP، TAR.GZ، أسماء عربية، Zip Slip، Archive Bomb، حدود المسارات، SQLite، القنوات، الحظر، واختبار الاشتراك واستثناء المدير. اختبار RAR/7Z الفعلي يعتمد على وجود أدوات 7-Zip وملف عينة صالح.

## حدود Telegram والاختبار الحي

تم تنفيذ **LOCAL TEST** فقط. لم يتم تنفيذ **TELEGRAM LIVE TEST** في هذه البيئة لعدم وجود توكن حقيقي، لذلك لم يتم الادعاء باختبار `/start` أو API أو قناة فعلية. حدود تنزيل وإرسال الملفات تعتمد أيضًا على Telegram Bot API المستخدم.

## الأمان

كل عملية استخراج تعمل داخل `data/users/<user_id>/<job_id>/`، ولا يستخدم المشروع مجلدًا مشتركًا لكل المستخدمين. يتم رفض المسارات المطلقة، `../`، الروابط الرمزية، الملفات غير العادية داخل TAR، وتجاوزات الحجم/عدد الملفات. الرسائل والسجلات لا تطبع التوكن.
